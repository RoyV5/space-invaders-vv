- **`Alien.Bomb`:** it is a non-static inner class (constructor `Bomb(Alien, int, int)` per `javap`), so BM-* tests create bombs with `owner.new Bomb(x, y)`.
- **Sprite placement:** in Board-level cases, sprites are built and then placed with `setX`/`setY`, so those cases do not depend on the constructor defects found in AL/SX.
- No expected value from the CSV was changed.
